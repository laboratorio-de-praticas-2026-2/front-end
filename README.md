# Front-end

Este repositório corresponde ao front-end do projeto Portal Contábil (Laboratório de Práticas 2026-2).

## Descrição do Projeto

O Portal Contábil é uma plataforma digital que tem como principal objetivo facilitar a gestão contábil, fiscal e tributária de pessoas físicas e jurídicas. Nosso foco é oferecer uma experiência de usuário intuitiva e completa, desde a consulta de obrigações fiscais (DAS, DARF, INSS, FGTS, IRPF/IRPJ) até a solicitação de serviços contábeis e agendamento de atendimentos com o contador responsável. Ele é responsável pela interface do usuário, consumindo a API fornecida pelo back-end.
