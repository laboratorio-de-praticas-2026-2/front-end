# Front-end | Portal Contábil
*(Laboratório de Práticas 2026-2)*

Este repositório contém a interface web do Portal Contábil. Ele consome a API do back-end para centralizar a vida fiscal do usuário, permitindo que pessoas físicas e jurídicas gerenciem impostos (DAS, DARF, INSS, FGTS, IRPF/IRPJ), solicitem serviços e agendem horários com o contador, tudo no mesmo lugar.
